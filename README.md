# Марсель — интерактивная квартира

3D-модель квартиры на Three.js: мебель и отделка, зеркала, ракурсы комнат, ночное освещение и дневной свет для Новосибирска.

## Запуск

Установите Node.js 22.13 или новее. Готовая модель включена в репозиторий, установка зависимостей для просмотра не нужна:

```sh
node serve.cjs
```

Откройте http://localhost:4175. Другой порт можно задать переменной `PORT`.

## Редактирование

Исходники находятся в `src`: `model-data.json` — геометрия плана, `scene.js` — построение модели, `interior.js` и модули комнат — мебель и материалы, `solar.js` — положение солнца, `main-interior.js` — интерфейс и управление сценой.

```sh
npm ci
npm run build
npm start
```

Сборка обновляет `site/model.js` и `site/model.css`. Текстуры встроены в `src/texture-urls.json`. Каталог `site` также можно размещать на статическом хостинге; сохранение PNG там выполняется скачиванием в браузере.

## Управление

- Левая кнопка мыши — вращение; правая — перемещение; колесо — масштаб.
- Ракурсы комнат, высота среза стен, отдельные переключатели зеркал.
- Дневной свет: 15 мая, июня, июля и сентября 2026 года; 10:00, 12:00, 14:00, 16:00, 18:00, 20:00 (Новосибирск, UTC+7).
- Ночной режим и отдельный режим низких светильников коридора.
- Сохранение ракурса в PNG и экспорт модели с текстурами в GLB.

Север привязан к схеме проекта. Расчёт солнца приближённый, по [формулам NOAA](https://gml.noaa.gov/grad/solcalc/solareqns.PDF); застройка и погода не моделируются точно.

Галерея содержит художественные изображения ImageGen. Для проверки геометрии и размеров используйте интерактивную модель. В репозиторий входит браузерный проект; исходные документы, резервные копии, видео и файлы Blender сюда не включены.
